## Paquetes de datos

Cuando envías un mensaje o cargas una web, los datos se dividen en pequeños fragmentos llamados **paquetes**. Cada paquete viaja de forma independiente por la red, tomando posiblemente rutas diferentes, y se reensamblan en el destino.

## TCP/IP: el idioma de Internet

El protocolo TCP/IP es el conjunto de reglas que define cómo se dividen, envían y reensamblan los datos. TCP garantiza la entrega correcta (verifica que todos los paquetes lleguen), IP se encarga del direccionamiento (que cada paquete llegue al destino correcto).

## La infraestructura física

Internet no es invisible: está sostenida por cables de fibra óptica submarinos que conectan continentes, centros de datos con miles de servidores, y antenas de radio para las conexiones inalámbricas. Cuando navegas, los datos pueden cruzar tres continentes en milisegundos.

## Datos curiosos

- Existen más de 400 cables submarinos que conectan los continentes y transportan el 99% del tráfico internacional de Internet.
- Si todos los servidores de Google se detuvieran, el tráfico global de Internet caería un 40%.
- El primer mensaje de Internet ('lo') se envió el 29 de octubre de 1969, y el sistema colapsó tras las dos primeras letras.

## Conclusión

Internet es una red descentralizada y robusta diseñada para sobrevivir fallos parciales. Su arquitectura de paquetes independientes la hace extraordinariamente resiliente: si un cable se rompe, los paquetes buscan otra ruta automáticamente.
